# Food Donation Management System

## About the Project

The Food Donation Management System is a web-based application developed to connect food donors with NGOs and facilitate the efficient redistribution of surplus food.

## Features

- User Registration and Login
- Role-Based Access
- Food Donation Management
- NGO Food Requests
- Request Approval and Rejection
- Food Pickup Management
- Donation Status Tracking
- Admin Management

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript
- PHP
- MySQL
- WAMP

## User Roles

### Donor
- Add food donations
- Manage donations
- View NGO requests
- Approve or reject requests

### NGO
- View available food donations
- Request food
- Track request status
- Manage food pickup

### Admin
- Manage users and system activities

## Project Objective

The main objective of this system is to reduce food wastage by connecting surplus food donors with NGOs and improving the distribution of food to people in need.
